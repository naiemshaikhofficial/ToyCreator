# Toy Creator — Audio Developer & Brand Publisher Portal

> **Official Creator Portal for ProducerToy Audio Marketplace**  
> *Create. Publish. Earn.*

Toy Creator is a standalone, dedicated creator platform for music plugin developers, VST architects, sample pack producers, preset designers, and digital audio software publishers.

---

## 🎹 Core Features

- **Brand Authentication & Access Control:** Strict authorization requiring an active registered brand in Supabase `brand_members` & `brands`.
- **Audio Product Publishing:** Direct CRUD for VST3/AU/AAX plugins, sample packs, synth presets, and DAW project templates.
- **Hardware DSP Licensing:** Native workstation seat management, SHA-256 hardware signatures, challenge-response pairing, and remote seat revocation.
- **Financial Ledger & Analytics:** Transparent 85/15 creator revenue schedule, real-time sales velocity charts, and instant payout disbursements via Stripe Connect & PayPal.
- **Priority Developer Desk:** Dedicated SLA ticketing desk linked directly to Supabase `support_tickets` with DAW & OS specs.

---

## 🛠️ Technology Stack

- **Framework:** Next.js (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Tailwind v4 with ProducerToy dark aesthetic tokens)
- **Database & Auth:** Supabase PostgreSQL (`voalgeyexfhfitlyorfl.supabase.co`)
- **Visuals & Charts:** Recharts & Lucide Icons
